DR. D. BURMAN - FREE PERSONAL DOCTOR APP

1. Edit script.js and replace WHATSAPP_NUMBER with the real WhatsApp number (country code, no + or spaces).
2. Replace the Call Now and WhatsApp links in index.html with the real phone/WhatsApp number.
3. Add chamber address and doctor photo if desired.
4. Upload the folder to any static hosting service. The site works as a PWA and can be added to an Android home screen.
5. For Google Play, this web app can later be packaged as an Android APK/AAB.
